# Between の「全画面通知を許可」をすぐ開くショートカット（Android）

以下は **Between** アプリの通知設定（「全画面通知を許可」などがある画面）へ素早く移動できる
ホーム画面ショートカットの作り方です。Android 標準機能だけでは特定のアプリ設定画面に直接
ショートカットを作れないため、無料のショートカット作成アプリを使う方法を記載します。

## 方法A：Activity Launcher（おすすめ）

1. **Google Play** で「**Activity Launcher**」をインストール。
2. アプリを開き、検索欄に **Settings** と入力。
3. 一覧から **Settings** アプリ配下の
   - **`App notification settings`**
   - **`App info`**
   - もしくは **`App notifications`**
   など、アプリ通知設定を開く項目を探します。
4. 該当の項目を長押し → **「ショートカットを作成」**。
5. 作成されたショートカットをタップし、アプリ一覧から **Between** を選択。
6. **Between の通知設定画面**が開くので、
   **「全画面通知を許可」** をオンにします。

> 端末や Android バージョンによって、項目名が多少違うことがあります。

## 方法B：ショートカットメーカー（別アプリ）

1. **Google Play** で「**Shortcut Maker**」をインストール。
2. アプリを開く → **「アクティビティ」** を選択。
3. 一覧から **Settings（設定）** を選び、
   **アプリ通知設定**に該当するアクティビティを選択。
4. **「作成」** → ホーム画面にショートカットを追加。
5. ショートカットをタップ → Between を選択 → 通知設定へ。

## もし項目が見つからない場合

- Android のバージョンによっては **「アプリ通知設定」** への直リンクが無いことがあります。
- その場合は **「アプリ情報」** へのショートカットを作り、
  そこから **通知** → **全画面通知を許可** に進むのが確実です。

---

これで **Between の「全画面通知を許可」** をすぐ開けるショートカットが作れます。
